# Awesome AI IDEs & Tools

A curated list of AI-powered Integrated Development Environments (IDEs), code editors, and intelligent coding assistants. This repository aims to provide a comprehensive guide to the best AI tools for modern software development.

## 🚀 AI-Native IDEs (Desktop)

These IDEs are built from the ground up with AI as a core feature, offering deep integration with your codebase.

| Name | Developer | Description | Key Features | Links |
| :--- | :--- | :--- | :--- | :--- |
| **Cursor** | Anysphere | The most popular AI-native code editor, forked from VS Code. | Codebase indexing, natural language edits, Composer mode. | [Website](https://cursor.sh/) |
| **Windsurf** | Codeium | The first "agentic" IDE featuring "Flow" for seamless AI collaboration. | Context-aware, autonomous refactoring, multi-file editing. | [Website](https://codeium.com/windsurf) |
| **Trae** | ByteDance | An adaptive AI IDE designed to understand developer intent. | "Builder Mode" for end-to-end tasks, adaptive learning. | [Website](https://www.trae.ai/) |
| **Zed** | Zed Industries | A high-performance, multiplayer editor written in Rust. | Blazing fast, built-in AI chat, collaborative coding. | [Website](https://zed.dev/) |
| **Void** | Community | An open-source, privacy-focused alternative to Cursor. | Self-hosted models, privacy-first, VS Code compatible. | [Website](https://voideditor.com/) |
| **PearAI** | PearAI | An open-source AI code editor focused on transparency. | Open-source, community-driven, extensible. | [Website](https://trypear.ai/) |
