# Awesome AI IDEs & Tools | AI 编程工具大集合

这是一个精心挑选的 AI 驱动的集成开发环境 (IDE)、代码编辑器和智能编程助手列表。本仓库旨在为现代软件开发提供最全面的 AI 工具指南。

## 🚀 AI 原生 IDE (桌面端)

这些 IDE 从底层开始就将 AI 作为核心功能构建，提供了与代码库的深度集成。

| 名称 | 开发者 | 描述 | 核心特性 | 链接 |
| :--- | :--- | :--- | :--- | :--- |
| **Cursor** | Anysphere | 目前最受欢迎的 AI 原生编辑器，基于 VS Code 开发。 | 代码库索引、自然语言编辑、Composer 模式。 | [官网](https://cursor.sh/) |
| **Windsurf** | Codeium | 首款“智能体” IDE，具有“Flow”功能，实现无缝 AI 协作。 | 上下文感知、自主重构、多文件编辑。 | [官网](https://codeium.com/windsurf) |
| **Trae** | 字节跳动 | 能够理解开发者意图的自适应 AI IDE。 | “Builder 模式”处理端到端任务，自适应学习。 | [官网](https://www.trae.ai/) |
| **Zed** | Zed Industries | 使用 Rust 编写的高性能、多用户协作编辑器。 | 极速响应、内置 AI 聊天、协作编程。 | [官网](https://zed.dev/) |
| **Void** | 社区 | Cursor 的开源、注重隐私的替代方案。 | 支持私有化模型、隐私优先、兼容 VS Code。 | [官网](https://voideditor.com/) |
| **PearAI** | PearAI | 专注于透明度的开源 AI 代码编辑器。 | 开源、社区驱动、可扩展性强。 | [官网](https://trypear.ai/) |
